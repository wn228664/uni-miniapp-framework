# 代码质量与注释标准

适用本框架的自有 JS、Vue、样式与配置；第三方源码保持由依赖管理。功能完整性、可读性、错误边界与验证证据共同验收。

## 代码质量

| 维度 | 执行要求 |
| --- | --- |
| 职责与复用 | 页面组合、组件展示、控制器状态、平台适配分层；封装对应实际复用或平台差异 |
| 命名与结构 | 名称说明用途，控制复杂分支和体量，删除死代码、无用样式与重复导入 |
| 参数与错误 | 明确输入范围、默认值、空值、同步抛错和Promise拒绝；失败应可观察和恢复 |
| 异步与资源 | 明确任务owner、防重、取消、超时、会话/刷新代次、监听和计时器释放 |
| 组件契约 | props、emits、暴露方法、插槽和父级责任可在源码与使用指南互相核对 |
| UI | 检查长文本、窄屏、宽屏、短屏、独立滚动、键盘、焦点与禁用状态 |
| 验证 | lint和格式检查、行为回归、平台编译、目标环境实际操作分别记录；未验证项公开保留 |

体量阈值用于触发审查，函数围绕完整职责组织。自有源码的审查不等于第三方依赖安全审计，也不等于微信真机验收。

## 注释内容

- 公共函数的非显然契约：用途、参数与单位、默认值、返回值、空值、错误方式、副作用和生命周期责任。
- 公共组件：数据由谁持有，何时发出事件，暴露方法的含义，关闭/隐藏/销毁后如何处理任务。
- 并发、权限、缓存、平台差异和兼容处理：解释原因、边界和失效条件，靠近对应代码。
- 使用中文说明，API名称与错误码保持原样；复杂API使用JSDoc辅助JS编辑器提示。
- 自解释import、局部赋值和常见样板无需模板注释。禁止逐行翻译、施工过程、过期TODO、注释掉的旧代码和与实现不符的保证。
- 函数行为或参数变化时同步更新注释、指南及回归用例；源码说明与文档冲突视为需要修正的问题。
