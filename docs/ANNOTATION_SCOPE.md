# 注释范围

手写 JavaScript、Vue 的声明、参数和回调在源码中说明用途、默认值、失败及取消责任。组件 props 紧邻字段说明，模板中的循环变量和 action 单独标注。SCSS 和 CSS 主题变量说明各自使用场景；测试 fixture 的完成入口、替身和清理回调也属于注释范围。

JSON 由平台和包管理器直接解析，不插入注释。`pages.json` 定义主包、分包、页面路径、导航与 easycom；新增页面要同步 `app/services.js` 白名单。`manifest.json` 定义公开平台标识和权限，默认关闭统计，微信域名校验保持开启；实际 appid 从环境注入。`package.json` 和锁文件分别声明命令/依赖与精确解析结果，依赖来源见 `DEPENDENCIES.md`。

`dist`、`node_modules`、字体和图像是生成或二进制资源，不人工注释。框架不修改第三方源码；许可证保留原文。微信工具配置、真机交互和真实服务接入仍需在对应环境验证，H5 构建不能代替这些结果。
