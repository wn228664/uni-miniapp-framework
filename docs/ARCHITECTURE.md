# ADR-001：独立 JS 小程序框架

状态：当前实施方案。日期：2026-11-03。

采用 uni-app / Vue 3 / JavaScript / Pinia / uview-plus 3.8.138。微信小程序是交付目标，H5 是辅助组件预览。源码不使用 TypeScript，框架不带业务模块、默认后端、账号或发布凭证；其它原项目只读。

uview-plus 是 uView 的 Vue 3 移植分支。保留 Vue 3 工程与 JS 编写方式，使用 easycom 按需解析组件。UI 库承担基础视觉；AppControl/AppSwitch 统一触控和键盘入口，AppButton/AppForm/AppDialog/AppUpload 补任务生命周期与错误恢复。不会用 UI loading 替代防重、取消和会话隔离。

页面 → 通用组件 → 控制器/Pinia → 注入服务 → core/platform。core 不依赖 Vue 或微信容器，可注入平台适配器做测试；平台 API 显式引用以配合 uni-app 按需编译。主包保留首页与共享能力，展示页面归入 showcase 分包。

约束：同步占锁；请求代次、会话 revision 与分页 epoch 防止旧结果回填；取消先结束 Promise 再中止平台 Task；刷新失败保留已加载内容和页码；字段提交使用标量快照；日期保存本地日历字符串；公开 HTTP 响应必须有有效状态。

页面负责 onHide 取消前台任务，组件负责 scope 销毁；后台任务使用独立 owner。客户端权限只控制入口，最终鉴权由服务端处理。真实接口响应、上传 decode、幂等和权限规则由新应用依据契约注入。

布局采用流式内容和有上限的宽容器；按钮可增长以容纳长标签。页面使用原生滚动，弹窗正文独立滚动，标题和操作区保持可达。目标尺寸通过实际预览量测；微信安全区、系统键盘和字体缩放由目标环境验收。

构建约束：DCloud 包统一版本；uView H5 的整库 eager 注册在锁定版本的入口处被构建适配器跳过，easycom 保持生效。入口变化立即停止构建，避免静默失效。主题 SCSS 变量放 uni.scss，基础样式只在 App.vue 引入一次。

验证分层：纯控制器测试、静态检查、干净安装、微信编译、H5 实际交互与多尺寸布局。H5 不替代微信运行；剩余依赖告警不标成已修复。当前证据见 VALIDATION.md。

日志仅记录错误类别；不记录凭证、完整响应或用户输入。会话默认仅内存保存，普通偏好使用命名空间存储。回滚仅恢复新工程快照，不触及原仓库。
